# SARMAT DOORS B2B READY15 — FINAL PRINT FIX

Тестовая/рабочая версия B2B-конфигуратора SARMAT DOORS с раздельными этапами коммерческого предложения.

## Как теперь работает КП

1. **Сформировать коммерческое предложение PDF** — формирует предпросмотр настоящего КП A4 без подписи и печати.
2. **Печать / сохранить в PDF** — открывает отдельный печатный макет КП, а не страницу сайта. Макет рассчитан на A4 и автоматически разбивается на 2/3/4+ страницы при необходимости; шапка и подвал повторяются на страницах.
3. **Скачать PDF** — скачивает тот же вариант КП без подписи и печати.
4. **Сформировать заказ** — отправляет полный заказ в Telegram. После успешной отправки сервер формирует финальный PDF с подписью и печатью и отправляет его в Telegram.
5. **Скачать финальное КП с печатью и подписью** — появляется только после успешной отправки заказа.

## Важные исправления

- Удалены общие утверждения о толщине всех дверей. Толщина полотна и коробки указывается только в конкретной позиции заказа.
- Используется отдельная шапка `sarmat_header_crop.jpg`, соответствующая согласованному образцу.
- Ценовые колонки таблицы выделены светло-золотым фоном.
- Таблица повторяет заголовок на каждой странице и не режет строку позиции между страницами.
- Условия поставки и оплаты идут после таблицы.
- Подпись и печать отсутствуют в предварительном/обычном КП.
- Подпись и печать присутствуют только в финальном КП после Telegram-отправки.
- Убран checkpoint: в проекте нет ссылок на checkpoint.
- Добавлен тайм-аут API 45 секунд и понятное сообщение при недоступности Render API.
- Кнопки PDF временно блокируются только во время операции, после ошибки автоматически разблокируются.
- Печать больше не зависит от открытия PDF viewer: печатается отдельный HTML-макет КП.

## Запуск

```bash
pip install -r requirements.txt
python server.py
```

Открыть `http://localhost:8080`.

Для Telegram задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в переменных окружения или `.env`.

## Render

`render.yaml` использует:
- `python server.py`
- health check: `/api/health`
- `PORT` из окружения Render
